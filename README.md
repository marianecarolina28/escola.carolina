Sistema Escolar

 É uma plataforma digital projetada para centralizar e otimizar a gestão de dados educacionais.

O sistema permite cadastrar e consultar informações de alunos, professores, responsáveis, materiais e boletins, reunindo os principais dados escolares em um só lugar.

🎯 Objetivo

O objetivo do projeto é criar um sistema simples para organizar os dados da escola e facilitar o acesso às informações dos estudantes e professores.

⚙️ Funcionalidades

👨‍🎓 Cadastro de estudantes
👨‍🏫 Cadastro de professores
👤 Cadastro de responsáveis
📖 Cadastro de matérias
📝 Cadastro e consulta de boletins
🔍 Consulta de informações dos alunos
🏫 Organização dos dados escolares
🛠️ Tecnologias utilizadas

HTML
CSS
PHP
MySQL
XAMPP
💻 Como executar o projeto

Instale o XAMPP.
Coloque a pasta do projeto dentro da pasta "htdocs".
Abra o XAMPP e inicie o Apache e o MySQL.
Crie o banco de dados no phpMyAdmin.
Importe o arquivo ".sql" do projeto.
Acesse o sistema pelo navegador através do endereço local do projeto.
👥 Projeto

Projeto desenvolvido para fins escolares, com o objetivo de praticar desenvolvimento web, banco de dados e organização de sistemas.
